# NOTERA AI — 上課筆記 AI 整理工具

把上課的影片、圖片丟上去，AI 幫你擷取重點、做 OCR、去掉重複的內容，整理成有結構的筆記，支援中文、日文、英文。

## 為什麼做這個

- 學校課業很重，筆記多到抄不完。
- 我是外國學生，日文閱讀速度比較慢。
- 老師用 Google Meet 直播上課，會錄影、截圖，講義也是拍照後電子化——這些素材很適合拿來做自動整理。

一開始本來想做 OCR 加文字模型兩段式，後來發現 VLM 一步就能搞定，就改用了 VLM。

## 功能

- 上傳上課影片 / 圖片
- AI 做場景擷取、OCR、去重
- 生成結構化筆記
- 支援中、日、英三語

## 技術棧

- 前端：Vue 3
- 後端：FastAPI
- AI：本地 VLM（Qwen 2.5 VL，後來換成 qwen3-vl）＋ PaddleOCR-VL
- 模型運行：Ollama
- 部署：Docker

## 限制

我自己的電腦算力不夠，短片可以處理，太長的影片跑不動。接上雲端 AI 的話會是更完整的版本。
